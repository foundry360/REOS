# Support sub-account

Ops location for Referral Partners. Not a customer REOS product account.

## Pipelines

| Pipeline | Use |
|---|---|
| **REOS Onboarding** | Track Snapshot installs (New → Snapshot loaded → Connections → Testing → Live → Closed) |
| **Support** (tickets) | Customer help requests (separate from onboarding) |

Customers never work these boards. Public form only for intake.

## Onboarding intake

1. Public form (basics: name, email, phone, company, etc.)  
2. Workflow on Form Submitted → Contact + Opportunity on **REOS Onboarding**  
3. Team uses [`ONBOARDING.md`](ONBOARDING.md) / CSV while moving the opp stages  
4. Real product setup happens in the **customer REOS** sub-account after Snapshot  

## Do not put here

- REOS Concierge / Scheduler / Follow-Up as the client’s live system  
- Customer-facing “ticket pipeline” UI  
- Expectation that Sales Closed Won alone creates the customer REOS account (form + human/automation create it)
